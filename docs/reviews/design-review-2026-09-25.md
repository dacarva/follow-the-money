## Pass 1: Information Architecture — 3/10 → 8/10

Screen inventory (1A). Each lists what the reader sees first / second / third.

```
 /  Inicio (2A)          1 search field (visible label "Buscar por nombre, NIT o cédula")
                         2 three example searches (company NIT, company name, agency)
                         3 "Datos SECOP II y RUES a corte <fecha>" · Metodología · CC BY-SA footer
                         No hero image, no feature grid.
 /buscar?q=              1 result rows: type icon, name, masked ID or company NIT, municipality,
                           contract count, last SECOP date (exact-ID match first, then trigram)
                         2 result count + type filter (Empresa / Persona / Entidad pública)
                         3 query help ("NIT con o sin dígito de verificación")
                         full-ID exact match → redirect straight to the entity
 /entidad/:ulid company  1 header strip: name, NIT, RUES status chip, actions (3A)
   (reference mockup)    2 breadcrumb trail + graph (focus centered) + card counts incl.
                           "Comparte representante legal con N empresas" (4A)
                         3 Conexiones table (all edge kinds) · evidence drawer on selection
 /entidad/:ulid person   1 name + masked ID (***1234) + roles as plain counts
                           (rep. legal de N empresas · ordenador en N contratos · supervisor en N)
                         2 graph   3 table + drawer
 /entidad/:ulid agency   1 name + NIT + contracts by year
                         2 graph with contractors aggregated by year/contractor
                         3 table + drawer
 /entidad/:ulid split    "Esta entidad fue dividida": chooser listing the new entities
 /correccion?e=:ulid     1 request type (consulta / reclamo) 2 form 3 legal text
                         → confirmation with ticket ID and response deadline
 /metodologia            edge kinds + legend, masking, "reportado en SECOP" vs "vigente a corte",
                         "en revisión", licenses, known limits
 staging /login          magic-link email field (staging only)
```

- Actions (3A): header strip above the graph holds Copiar enlace, Descargar PNG and a text link "Solicitar corrección"; always visible. The drawer holds evidence only, with one license line per record; the full license line lives in the footer.
- Finding line (4A): "Comparte representante legal con N empresas" on the card; click filters the table and highlights those companies; omitted when 0. Counts only; no hub label (R12).
- Labels (5A): person→company edges read "rep. reportado en SECOP" or "rep. vigente a <corte> (RUES)"; arrow person → company. "Comparte representante con <empresa>" appears only as a table row type and as the drawer summary listing both records.
- Ordenador (6A): one contract edge per agency with a count and value; ordenador del gasto and supervisor attach to the agency node, labeled "ordenador del gasto · N contratos con esta empresa"; expanding the edge lists the contracts in the table.
- Why 8, not 10: the person and agency pages have text specs but no mockup yet.

## Pass 3: User Journey & Emotional Arc — 3/10 → 8/10

```
 STEP | USER DOES                          | USER FEELS              | PLAN SPECIFIES?
 1    | Opens / from a colleague's tip     | "is this legit?" (5 s)  | yes: search-first home, cutoff date, sources (2A)
 2    | Searches a NIT                     | impatient               | yes: full-ID match jumps to the entity (1A)
 3    | Reads the entity card              | orientation             | yes: header, counts, finding line (3A, 4A)
 4    | Clicks "Comparte rep. con 4"       | first "whoa"            | yes: filters table, highlights graph (4A)
 5    | Opens a link's evidence            | skeptical ("prove it")  | yes: summary + full record fields (10A)
 6    | Clicks "Ver registro oficial ↗"    | verification            | yes
 7    | Writes it up                       | needs to cite           | yes: "Copiar cita" (11A)
 8    | Expands more hops                  | risk of getting lost    | yes: breadcrumb trail, undo, volver al foco (18A)
 9    | Shares link or PNG with editor     | confident               | yes: full view state URL (19A), print PNG (20A)
```

- Drawer (10A): summary line on top, source-qualified, e.g. "Ambas empresas tienen a María P. Ortega (C.C. ***7730) como representante legal reportado en SECOP. Las fechas en que ejerció el cargo no constan en estos registros." Each record: source, record code, company it belongs to, linking field (rep name + masked ID), contract object, value, signing date or "no reportada", contracting agency, observed date, "Ver registro oficial ↗", "Copiar cita". RUES records show "vigente a <corte>". > 5 records paginated with total.
- Citation (11A): "<Fuente>, <tipo de registro> <código>, <URL oficial>, consultado el <fecha>. Datos: datos.gov.co, CC BY-SA 4.0. Vía <producto> <URL de la entidad>." IDs always masked.
- Time horizons: 5 s = search + cutoff date + sources; 5 min = finding line → evidence → official record; 5 years = every claim traceable, no verdict words, citations carry attribution.
- Why 8: the journey is untested with journalists until the typical-task test (R21).

## Pass 4: AI Slop Risk — 6/10 → 8/10

- Classifier: APP UI (OPERATE); `/` and `/metodologia` are READ-leaning pages inside the same shell. No hard rejections.
- Look: near-black + neon is one of the three default AI looks, but it was explicitly chosen (Arkham reference, office-hours), so it stays.
- 12A: plain dark canvas, no grid-paper background; nodes and lines flat at rest; glow only on the selected node/edge, its path, and the highlighted "comparte representante" set.
- 13A motion: new nodes emerge from the parent (200 ms, ease-out) with existing nodes pinned; "Ajustar vista" animates the fit; table-row selection pans to the node (250 ms); drawer slides in (150 ms); nothing else animates; `prefers-reduced-motion` → instant.
- Why 8: brand distinctiveness waits on the product name (21A) and DESIGN.md typography (14A).

## Pass 6: Responsive & Accessibility — 0/10 → 9/10

- 16A breakpoints:
  - ≥ 1280px: reference layout (card, graph, table, drawer).
  - 768-1279px: card collapses into the header strip; drawer becomes an overlay.
  - < 768px: header (name, ID, status, Copiar enlace, PNG, "⋯" menu, visible "Solicitar corrección"), card counts incl. finding line, tabs "Conexiones" (default, grouped list) | "Grafo" (full screen, pan/zoom, tap to select), drawer as bottom sheet. 44px touch targets.
- 17A WCAG 2.2 AA:
  - The Conexiones table is the accessible equivalent: rows reachable by Tab/arrows, Enter opens the drawer, "Expandir" button per row.
  - Graph canvas `aria-hidden` with a text summary ("Grafo: 31 contratos con 3 entidades, 1 representante legal, 3 empresas que comparten representante").
  - Landmarks: header, search, main, complementary (drawer), footer. Drawer traps and returns focus; Esc closes.
  - Visible focus rings; 4.5:1 for body and metadata text; 44px targets; `lang="es-CO"`.
  - Masked IDs read as "cédula terminada en 7730".
  - CI: axe checks inside the Playwright E2E flows.
- Why 9: contrast can only be measured once DESIGN.md sets colors.
