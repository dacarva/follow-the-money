## Affected Pages/Routes
- `/` search: name, NIT (any formatting), full cédula; results show masked natural-person IDs; per-IP rate limit returns a clear message.
- `/entidad/:ulid` entity page: card with plain source counts ("N contratos como ordenador del gasto", "representante legal de N empresas"), no hub label; "vínculo en revisión" marker when a suspect edge exists; "Solicitar corrección" link.
- `/entidad/:ulid` graph expand: at most 50 neighbors per edge kind; overflow as aggregate nodes "N contratos más" by agency (by year for one agency); drill-down pages of 50.
- Evidence drawer: every edge lists its source record(s) with "Ver registro oficial ↗"; derived shared-rep link lists both records; CC BY-SA 4.0 attribution; "fecha de firma no reportada" where SECOP has no signing date.
- Redirected / split entity URLs: merge redirects; split shows "esta entidad fue dividida" chooser.
- Correction form: ticket ID issued; consulta vs reclamo types.
- PNG download: attribution + CC BY-SA 4.0 notice embedded; no full natural-person ID.
- Staging only: Supabase Auth login (magic link, email allowlist); unauthenticated or non-allowlisted access denied. Production: no login anywhere.
- API: `/search`, `/entity/:id`, `/entity/:id/expand?kind=&cursor=`, `/edge/:id/evidence` (license + attribution fields).

## Key Interactions to Verify
- Expand a company whose SECOP contract carries a legal-rep ID: edge labeled "representante legal reportado en SECOP para este proveedor" with source and observed date, and no signing-date claim (the contract node shows its own signing date).
- Expand a company with no SECOP rep: RUES current-rep edge labeled "representante legal vigente a <fecha de corte> (RUES)", visually distinct from the SECOP-reported edge, never attached to a contract date.
- From a legal rep, expand "other contractors": ordering by contract value desc, then date desc.
- Expand a high-degree ordenador del gasto (thousands of contracts): page stays responsive; aggregates appear; drilling one aggregate loads the next 50.
- Share the URL of an expanded graph; open in a fresh browser; same state.
- Download PNG of current view; inspect notice and IDs.
- Submit a correction request; receive ticket ID.

## Edge Cases
- Search with dotted/hyphenated NIT (`860.007.336-1`) and bare digits: same entity.
- Search with a placeholder (`Sin Descripcion`, `0`, `1`): no entity returned.
- Natural-person NIT whose base equals a cédula: joined only when person-type signals agree.
- Legal-entity NIT never merged with a cédula.
- Public entity as contractor (interadministrativo): normal edge, not suspect.
- Agency contracting itself, or agency NIT in a legal-rep field: suspect, hidden, marker shown.
- Names on one ID differing only by abbreviation or "S.A.S" vs "SAS": not suspect.
- Suppressed person: no placeholder and no edges through them; companies are no longer linked via that person; search by name/cédula returns nothing; takes effect as soon as the maintainer's action commits.
- Maintainer resolves a suspect ID, merges or splits an entity: search, expand and entity-card counts change immediately; old URLs redirect or show the split chooser.
- A source row edited at datos.gov.co: the site shows the new value; the Ley 1581 access export still lists the prior version with its dates.
- A deleted source row that reappears later: visible again after the next pull.
- Source row deleted at datos.gov.co: disappears from public views after the weekly sweep; still present in a Ley 1581 access export.
- Supabase Data API with the publishable key: every app table denied.
- Zero search results; single-character query; API 5xx during expand (retry message, no blank graph).

## Critical Paths
- Typical-task test (launch gate): 3 journalists × 5 randomly drawn contractors (3 companies, 2 natural persons); a correct connection or a correct "nothing in the data" within 5 minutes on ≥ 70% of the 15 tasks.
- Performance gate: server-side p95 ≤ 300 ms for search and ≤ 500 ms for expand on national data, including top-100 hub nodes.
- Sunday path: NIT search → entity → expand legal rep → other contractor → evidence drawer → SECOP record link, under 2 minutes.
- Privacy: no response body, URL, entity ID or PNG contains a full natural-person cédula or natural-person NIT in any formatting.
