## Key Interactions to Verify
- Sort the Conexiones table by Contratos on a hub with > 50 rows: first page is the true top across all rows
- Click "Comparte representante legal con N empresas": filter applies server-side, "Mostrando X de Y" matches
- Select a grouped contract edge, copy the link, open it in a fresh browser: same edge selected, same drawer records
- Expand a node with a kind filter, share, reopen: identical nodes
- Submit a correction: confirmation shows the legal term and a "fecha estimada"; maintainer email sent
- Export PNG: real fonts in the image (fonts awaited before draw)

## Edge Cases
- Contract with value 8.8e20 COP: excluded from sums, sorted after valued rows, drawer shows raw value + neutral note (R29)
- Natural-person "Prestación de servicios" at COP 29 billones: flagged
- Reported value 0 → "COP 0"; empty value → "sin valor reportado" (R43)
- Nightly ingest between table page 1 and page 2 → "Los datos se actualizaron; la lista se reinició"
- Merge later split: the next visit to the old URL follows the new target (no cached 301)
- Correction submitted on a Friday before a Monday holiday: deadline skips the festivo; incomplete reclamo paused
- Font fetch: CI cache empty + private store + Fontshare down → production build fails; tampered file fails the hash check
- No request leaves the site's origin on any page (fonts, scripts)
